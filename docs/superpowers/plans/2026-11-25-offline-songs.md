# Unduh Lagu untuk Offline

**Tujuan.** Unduh satu lagu dari menu lagu, lihat progres dan daftar unduhan di Library → Offline, putar ulang tanpa internet, dan hapus salinannya dari perangkat.

- [x] Tes bahwa unduhan gagal atau terputus tidak tampil sebagai lagu siap putar dan bahwa unduhan lengkap dapat dibuka dari penyimpanan lagi.
- [x] Tambah penyimpanan privat dengan identitas lagu yang sama, penanda selesai atomik, dan sampul serta lirik bila tersedia.
- [x] Gunakan resolver AAC dan transfer Ktor bertahap. Tampilkan antrean, progres, batal, dan coba lagi.
- [x] Utamakan audio lokal saat memilih lagu walaupun alamat streaming sudah disiapkan, sambungkan sampul dan lirik yang tersimpan, dan tambahkan filter Offline.
- [x] Jalankan build dan tes Android.
- [ ] Uji unduh serta putar dengan mode pesawat di perangkat iOS dan Android ketika perangkat tersedia.
